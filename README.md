# StageDesigner

App per macOS per disegnare stage plot: pianta del palco vista dall'alto con
strumenti, backline, monitor e scenografia in scala reale, lista canali e
lista uscite, esportazione in PDF e PNG con revisione e data di stampa.
Interfaccia ed export in italiano o inglese.

*A macOS app for drawing stage plots: a top view of the stage with
instruments, backline, monitors and scenery at real scale, input and output
lists, PDF/PNG export with revision and print date. Italian or English.*

## Download

Scarica il file `.dmg` dall'ultima [release](../../releases/latest), aprilo e
trascina **StageDesigner** in **Applicazioni**.

L'app non è firmata con un certificato Apple: al primo avvio fai clic destro
sull'app → **Apri** → **Apri**. In alternativa, da Terminale:

```
xattr -dr com.apple.quarantine /Applications/StageDesigner.app
```

Requisiti: macOS 13 o successivo.

## Aggiornamenti

StageDesigner controlla questa pagina all'avvio (al massimo una volta al
giorno) e avvisa quando c'è una nuova versione. Il controllo si può
disattivare dal menu **StageDesigner → Controlla aggiornamenti all'avvio**.

Questo repository contiene solo le release; il codice sorgente è privato.
